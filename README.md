# SpaceBudsZ-Audio

تطبيق Kotlin لـ Android 12+ للتحكم في صوت الوسائط واختيار مخرج اختبار الصوت للهاتف أو Oraimo SpaceBuds Z OTW-625.

## الوظائف

- قراءة أجهزة إخراج الصوت المتاحة.
- اكتشاف SpaceBuds Z عند اتصالها عبر Bluetooth A2DP.
- اختيار SpaceBuds Z أو سماعة الهاتف أو التوجيه التلقائي لاختبار الصوت.
- التحكم في مستوى صوت الوسائط.
- ملفات صوتية SpaceBuds Z / هاتف / Flat.
- اختبار EQ وBassBoost وLoudnessEnhancer على جلسة الصوت الخاصة بالتطبيق.
- فحص اتصال Shizuku.
- لا ميكروفون ولا اتصال إنترنت ولا ملفات سجل من التطبيق.

## حدود Android

واجهة Android الموثقة تسمح لـ AudioTrack باختيار جهاز إخراج مفضل للمسار نفسه، لكنها لا تجعل تطبيقًا عاديًا يفرض EQ عالميًا على صوت كل التطبيقات. التأثيرات المستخدمة هنا مرتبطة بجلسة الصوت التي ينشئها التطبيق.

## Shizuku

إصدار تطبيق Shizuku الرسمي الحالي هو 13.6.0، بينما إصدار مكتبة API المستخدم في المشروع هو 13.1.5 لأنه الإصدار المنشور المتاح عبر Maven Central وقت البناء.

## البناء

GitHub Actions workflow باسم "Android APK" يبني "app-debug.apk" مع كل push إلى main أو عند التشغيل اليدوي.
